# Pac-Man

## Description

<!-- Goal of the project and a brief overview. -->
This is complete and playable Pac-Man game in Python, using
object-oriented programming, a simple graphical library (pygame), and a modular, reusable architecture.
Key skills have been developed:
- Project and team managment
- System architecture
- Work with graphics

## Instructions
Pacman can be ran with and without
<!-- Installation, compilation and/or execution (Makefile rules, how to launch: python3 pac-man.py config.json). -->

make install

make build
